Diseño de PCB en Altium Designer

Software estándar de la industria electrónica utilizado para dibujar conexiones en un esquemático y convertir ese diseño en una placa de circuito impreso profesional.

¿Qué es Altium Designer y Diferencias con KiCad?

En esta práctica usamos Altium Designer para dibujar las conexiones de un circuito en un esquemático y convertir ese diseño en una placa de circuito impreso. Aunque cumple el mismo propósito final que KiCad, operan en diferentes niveles de la industria.

KiCad Altium Designer
Software de Código Abierto (Open-Source): Completamente gratuito, ideal para estudiantes, makers, hardware abierto y empresas medianas. Software Comercial (Licencia Privada): Es el estándar de oro en la industria corporativa e ingeniería avanzada. Requiere licencia de pago (o universitaria).
Flujo de trabajo separado. Debes exportar la netlist y asignar huellas manualmente en un paso intermedio. Ecosistema unificado. Los esquemáticos, las huellas (footprints), los modelos 3D y las reglas de diseño conviven en un solo proyecto dinámico.
Librerías locales e instalación de plugins externos para conexión con fabricantes. Panel nativo "Manufacturer Part Search" integrado con bases de datos en la nube (proveedores, precios y stock en tiempo real).

Acceso y Licencia Universitaria

Dado que Altium Designer es un software comercial, necesitamos autenticarnos con las credenciales de la universidad:

  • En el panel License Management, selecciona la licencia Altium Designer Professional.
  • Revisa que en la parte superior aparezca Universidad Iberoamericana Puebla.
  • Si el espacio todavía no aparece, búscalo y solicita acceso. Cuando se autorice, cierra Altium y vuelve a abrirlo para verificar que ya aparece el espacio de la universidad.

Áreas Principales de la Interfaz

Editor de Esquemas y Projects

Projects: Panel izquierdo donde vemos el proyecto y sus documentos.
Editor de esquemas: En la hoja cuadriculada colocamos los símbolos de los componentes, cables y etiquetas.

Panels (Ej. Components)

El botón de la esquina inferior derecha permite abrir paneles clave como Projects, Components, Properties y el poderoso buscador Manufacturer Part Search.

Editor de PCB

En el área de la placa física acomodamos las huellas de los componentes, seleccionamos las diferentes capas (Top, Bottom, Mechanical) y trazamos las pistas de cobre.

Paso 1: Crear el Proyecto y el Esquemático

Inicialización del Proyecto

  • En File → New → Project, elige el espacio de la Ibero o Local Projects. Escribe el nombre del proyecto y pulsa Create (Ej. HolamundoB.PrjPcb).
  • Haz clic derecho sobre el proyecto y selecciona Add New to Project → Schematic. Se abrirá la hoja cuadriculada.
  • Pulsa Save y elige la carpeta de trabajo local. La hoja queda guardada como documento .SchDoc dentro de la jerarquía del proyecto.

Paso 2: Armar el Esquemático

Haz clic derecho en la barra superior para mostrar las barras Schematic Standard, Formatting, Utilities y Wiring. Primero se dibuja un recuadro para organizar las entradas y después se colocan los componentes (un conector, 2 resistencias, capacitor, inductor, transistor, diodo 1N4004 y LED 1206).

Dibujo y Selección de Piezas

HerramientaCómo se usa

Línea, rectángulo y polígono

 Abre las opciones del ícono de regla en Utilities y elige la figura. Sal con Esc. Con doble clic o Properties cambias el grosor y estilo. Arrastra las esquinas para ajustar.

Texto

 Coloca un texto sobre el recuadro. Haz doble clic para escribir "Entradas" y ajustar el tamaño de la letra.

Components & Details

 Pulsa Use Existing Components. En la lista All elige la familia y arrastra la pieza. Vital: En Details despliega Models para ver el símbolo, huella y 3D. Comprueba que aparezca la huella antes de usar la pieza.

Part Search y Rotación

 Abre Manufacturer Part Search desde Panels para buscar piezas en la nube. Para girar, selecciona el componente y pulsa la barra espaciadora.

Cableado y Etiquetas

HerramientaCómo se usa

Place Wire & Zoom

 Actívala desde Wiring o con Ctrl + W. Clic en el pin cuando se marque en rojo y clic al final. Usa Ctrl + rueda para Zoom y Shift + rueda para mover a los lados.

Puertos de Alimentación

 Desde el botón de tierra coloca GND. Haz clic derecho en ese botón para desplegar las opciones y colocar +12.

Net Label

 Abre el desplegable de Wire y elige Net Label. Colócala sobre el cable. Con doble clic cambia su nombre. Usa Ctrl+C y Ctrl+V para vincular dos puntos con el mismo nombre.

Annotate Schematics Quietly

 Ve a Tools → Annotation → Annotate Schematics Quietly y confirma. Esto asigna un identificador a cada pieza automáticamente (ej. Las resistencias pasan a llamarse R1 y R2).

Esquema Resultante

Así luce el circuito tras aplicar recuadros, conectar pistas, etiquetas de red y procesar la anotación silenciosa (R1, R2, Q1...).

Paso 3: Pasar el Esquemático a PCB y Rutear

Haz clic derecho en el proyecto y elige Add New to Project → PCB. Guarda el documento .PcbDoc en la carpeta de trabajo. (Los indicadores rojos en las pestañas señalan cambios sin guardar; usa Save All).

Desde el esquemático, selecciona Design → Update PCB Document. Se abrirá la ventana Engineering Change Order. Pulsa Validate Changes, revisa los avisos, pulsa Execute Changes y Close.

Las huellas de los componentes aparecerán abajo a la derecha en la zona negra. Selecciónalas y muévelas al área de la placa.

Haz clic derecho en la barra superior para mostrar PCB Standard, Filter, Utilities y Wiring.

  • Origen: Ve a Edit → Origin → Set y haz clic en una esquina del rectángulo para fijarlo.
  • Girar en PCB: Mantén clic izquierdo sobre el componente y pulsa la barra espaciadora.
  • Vista 3D: Pulsa 3 para ver la PCB en 3D. Pulsa 2 para regresar a 2D. (En 3D mantén Shift + clic derecho para girar la placa).
  • Filter: Elige una red como +12 o GND en la lista para resaltarla. Pulsa la X para quitar el filtro.
  • Unidades: Presiona Q para alternar entre mils y milímetros.

Reglas de Diseño (Design → Rules): Consulta el "Capabilities" de tu fabricante (ej. JLCPCB).
Revisa la sección Clearance para separación. En Routing → Width fija los anchos.

  • Top Layer: Min 0.1 mm | Preferido 0.4 mm | Max 0.7 mm
  • Bottom Layer: Min 0.254 mm | Preferido 0.254 mm | Max 0.8 mm

Interactive Routing: Selecciona Top o Bottom Layer, activa la herramienta y haz clic en el punto de inicio. Guía con giros de 45° (GND se deja al final).

Ancho de Pista: Durante el ruteo pulsa Shift + W para elegir otro ancho (el ancho se relaciona con la corriente).

Auto Route: Route → Auto Route. Permite rutear automáticamente todo (All), una red (Net) o una zona (Area).

Place Via: Agrega un punto de perforación metalizado para saltar entre capas.

Paso 4: Definir Contorno y Revisión

Contorno (Board Shape)

Para recortar la placa física, selecciona la capa Mechanical 1 y usa las herramientas de trazado (ej. dibujar un círculo alrededor de los componentes).

Selecciona la figura dibujada y ve a Design → Board Shape → Define Board Shape from Selected Objects. Al aplicar el comando, el área negra de la placa tomará exactamente la forma de la figura.

Pulsa 3 para ver el contorno físico terminado en el motor de renderizado 3D.

Interactive Length Tuning

Esta herramienta avanzada, ubicada en el menú Route, alarga una pista existente creando un patrón de zigzagueo (serpentina). En el diseño de alta velocidad, se utiliza para igualar las longitudes de las pistas y reducir el desfase temporal entre señales de comunicación.
